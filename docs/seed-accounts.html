API xác thực

Endpoint đăng nhập công khai, giới hạn rate limit. Trả về access token (15 phút) + refresh token (7 ngày).

POST /api/auth/login
Content-Type: application/json

{
  "email": "hr@kmart.vn",
  "password": "Kmart@123"
}
Response200·accessToken + refreshToken + user
Lưu ý bảo mật. Đây là tài khoản demo dùng chung một mật khẩu yếu. Sau khi nghiệm thu, hãy đặt lại mật khẩu riêng cho từng vai trò qua POST /api/users/{id}/reset-password (yêu cầu quyền USER_UPDATE) và không chia sẻ sheet này ngoài nhóm phát triển. Tài khoản ADMIN và HR có quyền bảo mật tối cao — hạn chế dùng trên môi trường production. JWT ký bằng HMAC-SHA256; sau 5 lần sai mật khẩu liên tiếp tài khoản sẽ bị khóa 30 phút.
