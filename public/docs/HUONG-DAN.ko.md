# KMart 시스템 사용 가이드

> **최종 사용자와 관리자**를 위한 안내서: 기안 작성, 승인, 결재 라인(flow) 설정, Telegram 사용,
> 위임, 보고서. 각 항목에 메뉴 경로를 명시해 그대로 클릭하면 됩니다.

---

## 1. 빠른 시작

- 회사 이메일과 인사팀이 발급한 비밀번호로 **로그인**합니다.
- 왼쪽 메인 메뉴: **부서 & 그룹**, **인사**, **기안**, **보고서**, **위임**, **설정**, **가이드**
  (일부 항목은 권한에 따라서만 표시됩니다).
- **VI / EN / KO** 버튼으로 화면 언어를 전환합니다.
- 오른쪽 상단 벨은 **앱 내 알림**이며, 중요한 알림은 Telegram 연결 시 **Telegram**으로도 발송됩니다.

### 비밀번호 재설정 후 첫 로그인

인사팀이 비밀번호를 재설정했다면 **비밀번호 변경 필요** 화면이 열립니다:

1. **현재 임시 비밀번호**: 인사팀이 발급한 임시 비밀번호를 입력(Telegram 또는 직접 수령).
2. **새 비밀번호**와 **새 비밀번호 확인**: 새 비밀번호를 설정.
3. 새 비밀번호는 입력란 아래 5가지 조건을 충족해야 합니다: 8자 이상, 대문자, 소문자, 숫자, 특수문자.
4. **비밀번호 변경 후 계속**을 눌러 진입. 입력이 틀리면 해당 입력란 아래에 구체적인 오류가 표시됩니다.

## 메뉴별 기능 한눈에 보기

| 메뉴 | 역할 | 표시 대상 |
|---|---|---|
| **부서 & 그룹** | 조직도, 부서 정보·구성원, 부서 내 기안 확인 | 전체 |
| **인사** | 사원 목록, 계정 생성, 비밀번호 재설정, 역할 부여 | HR / Admin |
| **기안 → 내 기안** | 기안 작성, 내 기안 추적, 보완·취소 | 전체 |
| **기안 → 내 승인 대기** | 담당 기안 처리: 승인, 반려, 보완 요청, 댓글 | 승인 권한자 |
| **보고서** | 종합 지표, 12개월 추세, 유형/부서별 분포, Excel 내보내기 | HR / Admin |
| **위임 → 임시 위임** | 부재 중 승인 권한을 타인에게 위임 | 승인 권한자 |
| **위임 → 기한 초과 대결자** | 기한 초과 시 기본 대결자 설정 | 승인 권한자 |
| **설정 → 양식 / 결재 라인 / 직위** | 기안 양식 설계, 유형별 결재 라인 구성, 직위 관리 | Admin |
| **설정 → 일반 & Telegram** | Telegram 봇 토큰, 웹, 시스템 파라미터 | Admin |
| **프로필**(이름 클릭) | 개인 프로필, Telegram 연결/변경, 연락처 수정 | 전체 |
| **가이드** | 지금 보고 있는 문서 페이지 | 전체 |

**역할별 읽기 팁:** 신입 사원은 1–3장, 승인자는 3.2와 6장, 관리자는 4장과 5.4절, HR은 7장.

## 2. 새 기안 작성 (단계별)

![기안 작성 3단계](/docs/img/tao-don.svg)

**기안 → 내 기안**에서 **새 요청 작성**을 누르면 대화상자가 열립니다:

1. **요청 유형**: 휴가, 야근, 구매, 출장 등 필요 유형 선택. 선택하면 해당 유형의 동적 양식(예: 시작일/
   종료일/총 일수)이 표시됩니다.
2. **양식 입력**: `*` 표시 필드를 모두 입력. 날짜는 내장 피커로 선택.
3. **결재 라인 미리보기**: 하단 **예상 결재 라인** 블록에서 통과할 승인자를 확인.
   **여기를 눌러 라인 상세 보기**를 누르면 발송자 → 단계별 승인자 → 완료 전체 도식과
   **기안 경로** 요약이 표시됩니다.
4. **지정 승인자**: 1단계에 승인 후보가 여러 명이면 **승인자 선택**에서 1명을 골라야 합니다.
   단일 지정 흐름이면 이름이 미리 표시되어 선택이 불필요합니다.
5. **사유 / 설명**: 승인자가 판단하기 쉽도록 명확히 기재.
6. **요청 제출** 클릭. 기안은 대기 상태가 되고 1단계 승인자에게 즉시 알림(앱 + Telegram).

**팁:** 제출 전 라인 도식을 열어 올바른 승인자에게 가는지 확인하세요. 잘못되었다면 라인 설정
문제이므로 관리자에게 문의(4장).

### 제출 전 최종 확인

- `*` 필드 전부 입력, 날짜 기간이 실제 필요 기간과 일치하는지.
- 라인 도식 최종 확인: 승인자, 단계 수.
- 유형이 허용하면 증빙 자료 첨부(재문의 방지).

### 제출 후 흐름

- 기안은 **대기** 탭으로 이동, 1단계 승인자에게 즉시 알림.
- 단계가 진행될 때마다 알림: 누가 승인했고 다음 단계는 누구인지.
- 급하면 승인자에게 직접 또는 Telegram으로 리마인드. 시스템도 기한 전에 자동 알림.

## 3. 기안 추적 및 처리

### 3.1 작성자로서

- **기안 → 내 기안**. 상태 탭: **전체**, **대기**, **보완 필요**.
- 기안을 클릭해 상세 확인: 현재 단계, 승인자, 다음 승인자, 이력, 댓글.
- **보완 요청** 시: 기안을 열어 요청 내용을 보완 후 재제출.
- 철회: **기안 취소**를 누르고 사유 기재.

### 3.2 승인자로서

- **기안 → 내 승인 대기**(또는 알림/Telegram의 **상세 보기** 링크로 바로 이동).
- 상세 화면의 3가지 주요 동작:
  - **승인**: 다음 단계로 이동, 최종 단계면 완료.
  - **반려**: 사유 필수, 작성자에게 사유 포함 알림.
  - **보완 요청**: 보완 내용 명시, 기안은 작성자에게 반환.
- **댓글**로 작성자 및 다른 승인자와 소통 가능.
- Telegram 메시지에는 유형명, 작성자, (2단계부터) 단계별 승인 내역 **진행도**가 표시되고
  **상세 보기**를 누르면 해당 기안으로 이동.

### 대기 기안이 많을 때 팁

- 목록을 훑지 말고 Telegram **상세 보기** 링크로 열기.
- 기한 임박 기안은 별도 알림 — 우선 처리.
- 조기 반려 대신 **댓글**로 문의하면 보완 후 빠르게 진행.
- 장기 부재 시 **임시 위임**(6장) 설정으로 적체 방지.

## 4. 유형별 결재 라인 설정 — 관리자

![다단계 결재 라인](/docs/img/luong-duyet.svg)

**설정 → 결재 라인**에서 유형별 **승인 단계**를 구성합니다. **다음 승인 단계 추가**로 단계 추가.

### 4.1 단계별 승인 방식

| 방식 | 의미 | 사용 시기 |
|---|---|---|
| **직속 관리자** | 작성자의 직속 관리자가 승인 | 표준 부서 흐름 |
| **관리 체인** | 하위 직급부터 상위 직급까지 순차 승인 | 여러 관리 결재 필요 시 |
| **배치 승인** | 규칙 + 직위/그룹 선택 | 직위별 맞춤형 흐름 |
| **특정 1인 지정** | 지정한 1명만 수신 | 담당자가 고정된 특수 기안 |

### 4.2 한 단계에 승인자가 여러 명일 때 규칙

- **순차 승인**: 앞 사람이 승인해야 다음 사람에게 이동(`A ➔ B ➔ C`). 순서 목록 필수 선택.
- **동시 — 전원 동의**: 전원에게 발송, 100% 승인 시 진행.
- **동시 — 1명만**: 먼저 승인하는 사람 기준으로 진행.

### 4.3 단계별 기한 초과 처리

**기한 초과 처리**를 켜고 허용 **시간**을 입력. 시간 초과 시 선택한 동작이 자동 적용:

- **작성자에게 반환**: 기안이 작성자에게 돌아감.
- **기한 초과 위임 승인**: 승인자가 설정한 대결자에게 이동(6장 참고).
- 또는 설정에 따라 상위 직급으로 에스컬레이션.

### 4.4 저장 및 검증

- **저장** 클릭. 시스템이 설정 오류(예: 순차 승인에 승인자 미선택)를 단계별로 구체적으로 알림.
- 검증: **새 요청 작성**에서 해당 유형을 선택해 **예상 결재 라인**이 설정과 일치하는지 확인.

## 5. Telegram 연결 및 사용

![Telegram 연결과 알림](/docs/img/telegram.svg)

### 5.1 첫 연결

1. **프로필** 페이지(왼쪽 상단 이름 클릭 → 프로필)로 이동.
2. **Telegram 연결** 클릭. 회사 봇이 열림.
3. Telegram에서 **Start** 클릭. "연결 성공!" 응답 후 알림 수신 시작.

### 5.2 다른 Telegram 계정으로 변경

- **프로필**에서 **Telegram 연결됨** 옆의 **Telegram 연결 변경** 클릭.
- 봇 링크를 열어 **새 계정으로 Start**. 기존 연결은 자동 교체.

### 5.3 수신하는 알림

- 내 기안 승인 / 반려 / 보완 필요 / 취소.
- 내 승인 대기 신규 기안, 기한 임박, 기한 초과 이동·취소.
- 인사팀 비밀번호 재설정 시 임시 비밀번호.
- 모든 메시지에 **상세 보기** 링크, 기안명·인물명은 **굵게** 표시.

### 5.4 관리자: 봇 설정

**설정 → 일반 & Telegram**: **봇 토큰** 붙여넣기, 연결 테스트, 웹훅 등록(Start 명령 수신).
봇 미설정 시 사용자는 연결 오류를 받고 앱 내 알림만 동작.

## 6. 위임 및 기한 초과 대결자

**위임** 메뉴의 두 페이지:

### 6.1 임시 위임(부재 시)

1. **위임 생성**에서 대결자와 적용 기간 선택.
2. 기간 중 나에게 올 기안이 대결자에게 이동, "누구를 대신해 승인" 기록.
3. 기간 종료 시 권한 자동 반환. 언제든 **담당자 변경** / **회수** 가능.

### 6.2 기한 초과 대결자(기본 설정)

1. **위임 → 기한 초과 대결자** 이동.
2. 기본 대결자 선택 후 **대결자 저장**.
3. 내 승인 기안이 기한 초과되고 흐름이 "기한 초과 위임 승인"을 켠 경우 해당자에게 이동.
   미설정 시 흐름 설정에 따라 취소/반환.

## 7. HR 담당자용

- **사원 계정 생성**: **인사 → 사원 계정 생성**에 이름, 이메일, 부서, 역할 입력. 사원은 임시
  비밀번호를 받고 첫 로그인 시 변경 필수.
- **비밀번호 재설정**: 사원 프로필 → **비밀번호 재설정**. 임시 비밀번호가 생성되어 HR 화면에
  표시되고 **사원의 Telegram으로도 즉시 발송**(연결된 경우).
- **역할 부여**: ADMIN / HR / MANAGER / TEAM_LEADER / STAFF 설정으로 메뉴·권한 제한.

## 8. 보고서 및 Excel 내보내기

![보고서와 Excel 내보내기](/docs/img/bao-cao.svg)

- **보고서** 메뉴(HR/ADMIN 권한).
- 필터 바(기간, 블록, 부서, 기안 유형, 직위)로 데이터 축소. 모바일에서는 **필터** 행을 눌러
  필터 영역 접기/펼치기.
- 지표 블록: 종합, 12개월 추세(**통합** / **유형별** 전환), 유형·부서별 분포, 부서/직위 비교, 운영 roster.
- 각 테이블의 **Excel** 버튼으로 현재 화면 그대로 내보내기.

## 9. 자주 묻는 질문 (FAQ)

**Q: 라인 도식에 이름 대신 "승인자"라고 나와요.**
A: 단일 지정 흐름이나 후보가 여러 명인 흐름은 선택이 완료되어야 이름이 표시됩니다.
**승인자 선택**에서 고른 뒤 도식을 다시 여세요. 여전히 잘못되면 관리자에게 라인 확인 요청(4장).

**Q: Telegram 알림을 못 받아요.**
A: **프로필**에 **Telegram 연결됨**이 표시되는지 확인, 아니면 재연결. 연결됐는데도 없으면 관리자에게
봇 설정 확인 요청(5.4절).

**Q: 내가 승인할 기안이 대기 목록에서 사라졌어요.**
A: 작성자 취소, 기한 초과 이동, 또는 "1명만 승인" 규칙에서 동시 승인자가 먼저 처리한 경우입니다.

**Q: 비밀번호를 잊었어요.**
A: HR에게 재설정 요청(7장). 임시 비밀번호를 Telegram 또는 직접 받아 로그인 후 즉시 변경(1장).

**Q: 승인 단계를 하나 더 추가하려면?**
A: 관리자가 **설정 → 결재 라인**에서 해당 유형 흐름을 열고 **다음 승인 단계 추가**를 눌러
새 단계의 승인 방식을 설정합니다(4장).
